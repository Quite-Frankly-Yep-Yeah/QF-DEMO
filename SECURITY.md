Please report vulnerabilities in quite frankly an example LMS to the maintainers of this project, using the contact
listed here once it is filled in. Do not use Instructure's Bugcrowd program or security contacts
for quite frankly an example LMS. Those cover Instructure's own upstream releases, not this project.

through Instructure's disclosure process: https://www.instructure.com/trust-center/vulnerability-disclosure
