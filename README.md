EXAMPLE LMS
======

EXAMPLE is an open-source [LMS](https://en.wikipedia.org/wiki/Learning_management_system)
released under the [AGPLv3](LICENSE) license for use by anyone interested in learning more
about or using learning management systems.

EXAMPLE is a modified version of [Canvas LMS](https://github.com/instructure/canvas-lms),
originally developed by [Instructure, Inc.](https://www.instructure.com/) and released under
the same license. It keeps the upstream plugin, LTI, and API interfaces, so it stays compatible
with Canvas plugins and LTI tools. See [NOTICE.md](NOTICE.md) for attribution and licensing details.

Installation
=======

Installation and configuration follow the upstream Canvas LMS documentation. Wherever those
guides say "Canvas", read "EXAMPLE".

 * [Quick Start](https://github.com/instructure/canvas-lms/wiki/Quick-Start)
 * [Production Start](https://github.com/instructure/canvas-lms/wiki/Production-Start)
